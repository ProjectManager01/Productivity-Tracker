# 🏔️ Bir-Billing High-Performance Operating System
### Strategic Protocol for Neuroplasticity, Endurance, and Longevity in a High-Altitude Environment

A responsive, cross-platform (Desktop & Android) daily tracking dashboard and protocol engine engineered specifically around the scientific research paper for high-performance living in **Bir, Himachal Pradesh (1,400m – 3,080m)**.

---

## ⚡ Key Modules & Evidence-Based Features

### 1. 🕒 Chronobiological Master Timetable (06:00 AM – 09:30 PM)
- **Real-Time Active Block Tracking**: Automatically highlights the current protocol block with real-time indicators based on your system clock.
- **One-Click Protocol Logging**: Track compliance for hydration, Wim Hof breathwork, morning altitude running, cold showers, 3x 90m deep work sessions, NSDR, optic flow chores, calisthenics, meals, Goggins mobility, wind-down, and sleep.
- **Protocol Adherence Score**: Computes daily execution percentages and streak metrics.

### 2. 🧠 Neurobiological Productivity & Learning Engine
- **3 × 90-Minute Ultradian Focus Bouts (BRAC cycles)**:
  - **Block 1 (09:00 - 10:30 AM)**: Visual Focus Primer (60s stationary gaze to recruit acetylcholine) + 10s random micro-rests for hippocampal replay consolidation.
  - **Block 2 (11:00 - 12:30 PM)**: Second cognitive peak with Physiological Sigh acute stress regulation.
  - **Block 3 (02:30 - 04:00 PM)**: Skill & reading session targeting an optimal **15% error rate** for synaptic remodeling.
- **Circadian Entrainment Tracker**:
  - Morning sunlight exposure (ipRGC melanopsin stimulation for Cortisol Awakening Response & dopamine).
  - **Delayed Caffeine Tracker**: 90-120 minute countdown post-waking to clear adenosine organically and eliminate afternoon crashes.
  - **NSDR (Non-Sleep Deep Rest) / Yoga Nidra**: 10-20 min restorative tool.
  - **Optic Flow Ambulation**: Walking and chores generate lateral retinal motion to down-regulate amygdala fear/stress activity.
  - **8.5-Hour Sleep Opportunity**: Log hours and morning restoration rating.

### 3. 🏃‍♂️ Concurrent Training Engine (Endurance vs. Hypertrophy)
- **Molecular Interference Prevention**: Enforces an 8+ hour temporal separation between morning running (AMPK / PGC-1α) and evening calisthenics (mTORC1 / protein synthesis).
- **Morning Altitude Marathon Training**:
  - Log Zone 2 base building (70-80% volume), Tempo / Lactate threshold work, Vertical Kilometer (VK) steep climbs, and Progressive Long Runs.
  - Tracks distance (km), elevation gain (m), pace, and heart rate.
- **Evening Hypertrophy Calisthenics**:
  - Upper Push, Lower Body, Upper Pull, and Full Body compound splits.
  - Built-in progressive leverage movements (Pseudo-planche push-ups, archer push-ups, pistol squats, shrimp squats, Nordic curls, front levers).
  - Enforces **3 to 4-second eccentric tempo** for localized tension and muscle damage.
- **David Goggins Mobility Protocol**:
  - Dedicated 4-station interactive timer with countdowns and audio prompts:
    1. Couch Stretch (Psoas & Hip Flexors, 3 min/side)
    2. Seated Figure-4 / Pigeon Pose (Glutes & Piriformis, 3 min/side)
    3. 70° Incline Calf & Achilles Stretch (2.5 min/side)
    4. Doorway Chest & Thoracic Spine Opener (3 min)
- **Morning Cold Shower Protocol (2-3 mins)**:
  - Spikes baseline dopamine and norepinephrine. Safely isolated to morning post-run to prevent blunting muscle hypertrophy.

### 4. 🍳 Nutritional Architecture & Recipe Directory
- **Anabolic Leucine Trigger Tracking**: Real-time visual progress bars verifying that each meal surpasses the critical **2.5g – 3.0g leucine threshold**:
  - **Breakfast: Air Fryer High-Protein Egg Bites**: ~32-35g Protein, ~2g Carbs, ~15g Fat, 3.1g Leucine.

- **Embedded Recipe Links & Media Hub**:
  - Direct video guides and YouTube links for air frying techniques and soya chunk preparation.
  - Authoritative blog links directly cited from the research paper (Health Beet, Love and Other Spices, YourTrainer, KABO, Natasha Mohan, Clearcals, Wonderchef, NNWA, Flavor Quotient, Spice Cravings).
- **Water & Electrolytes Tracker**: Morning 1L + pinch of sea salt for adrenal function.

### 5. 📱 Desktop & Android Access + Synchronization
- **Responsive PWA (Progressive Web App)**: Optimized for desktop browsers (sidebar + grid) and Android mobile devices (thumb-friendly bottom navigation, full-screen standalone mode).
- **Offline First**: Runs completely offline using LocalStorage and Service Workers.
- **Cross-Device Sync Options**:
  - **Method 1 (Local Wi-Fi Server)**: Run `node server.js` on desktop. Open `http://[your-ip]:3000` on Android Chrome. Tap "Add to Home screen" to install as a native app!
  - **Method 2 (Cloud / Room Sync Code)**: Enter any shared Sync Code (e.g. `bir-2026`) in Settings on both devices to automatically sync logs over the network.
  - **Method 3 (JSON Backup & Restore)**: Export or restore complete historical data anytime.

## 🚀 How to Run the App

### Option A: Local Node Server (Recommended for Desktop + Android Sync)
1. Open PowerShell or Terminal and navigate to the project folder:
   ```powershell
   cd C:\Users\Supreme\.gemini\antigravity\scratch\bir-protocol-tracker
   ```
2. Start the lightweight server:
   ```powershell
   node server.js
   ```
3. Open in your browser:
   - **On Desktop**: Open `http://localhost:3000`
   - **On Android Phone (Connected to same Wi-Fi)**: Open `http://192.168.31.85:3000` (or the IP displayed in the terminal output).
4. On Android Chrome: Tap **⋮ (Menu) -> Add to Home screen** or click **Install App**.

### Option B: Direct Browser Open (Offline Desktop)
- Simply double-click `index.html` or open `file:///C:/Users/Supreme/.gemini/antigravity/scratch/bir-protocol-tracker/index.html` in Chrome or Edge.
